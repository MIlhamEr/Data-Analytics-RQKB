# Data Analytics Quantium
This is a simulation of the data analyst role at theforage.com.
## What you'll learn
1. Understand how to examine and clean transaction and customer data.
2. Learn to identify customer segments based on purchasing behavior.
3. Gain experience in creating charts and graphs to present data insights.
4. Learn how to derive commercial recommendations from data analysis.
## What you'll do
1. Analyze transaction and customer data to identify trends and inconsistencies. 
2. Develop metrics and examine sales drivers to gain insights into overall sales performance. 
3. Create visualizations and prepare findings to formulate a clear recommendation for the client's strategy.
